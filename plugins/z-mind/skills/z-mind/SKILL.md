# Z-Mind Skill

Provides operational control and automated enforcement of senior engineering disciplines across all coding tasks.

## Capabilities & Sub-Skills

- **`/z-mind rules [topic]`**: Displays core engineering invariants (e.g. `tdd`, `perf`, `git`, `refactor`, `solid`).
- **`/z-mind investigate`**: Activates the 4-phase empirical bug investigation workflow (Sensory Sweep -> Socratic Inquiry -> Pre-Mortem -> Root Cause Fix).
- **`/z-mind refactor`**: Guides zero-regression refactoring enforcing the Net Engineering Value (NEV) gate.
- **`/z-mind team`**: Orchestrates multi-agent subagent teams with zero-collision file ownership contracts.
- **`/z-mind status`**: Reports active engineering guidelines and invariant compliance status.

---

## Operating Invariants

1. **Reproduction Before Fix**: Never modify production logic for a reported bug without an automated failing test first.
2. **Empirical Verification**: Claims must cite compiler exit code 0, test counts, or benchmarks.
3. **Context-Diet Compliance**: Keep communications dense and skimmable; avoid redundant narrative preamble.
